An empirical kernel-weighted comparable launch curve forecaster for make.fun's "Forecast GTA VI's launch-day Twitch viewers hour by hour" bounty.

It reads the initial hour-1 concurrent viewer count for GTA VI and projects hours 2 to 24 of the launch day as five quantiles (5%, 25%, 50%, 75%, 95%) by weighting 38 historical AAA launch curves on launch-scale proximity and console rolling-midnight release patterns.

## Run it

```sh
python3 main.py
```
